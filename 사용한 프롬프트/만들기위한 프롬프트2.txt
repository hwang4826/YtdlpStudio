# =========================
# yt-dlp 최신 업데이트 확인
# =========================
print("🔄 yt-dlp 최신 버전 확인 중...\n")

subprocess.run(
		f'"{YT_DLP_PATH}" -U',
		shell=True
)

이건 그냥 파일 켤 때마다 업데이트 해주면 좋긴 한데, 수동 업데이트도 있으면 좋으니까 구석에 버튼을 만들어줘.

그리고 0. 1. 2&3. 이거는 내가 프롬프트 입력이 편하도록 임의로 매긴 번호니까 지워주고, 쿠키 사용 뒤에 (멤버십, 성인인증 등)은 지워줘.

다중 다운로드가 가능했으면 하는데 원래 cmd 상태에서 다운로드 할 때는 여러 cmd 창을 띄워두고 명령어를 입력하면 각 cmd 창에서 병렬적인 다운로드가 가능했거든?
이게 exe파일 하나만 띄워놓고도 가능할까?

이렇게 엔터처리(혹은 "," 혹은 ", ")한 녀석들을 한 곳에 몰아넣고 병렬 다운로드를 하면 좋겠어. 안된다면 위부터 순서대로 직렬 다운로드하게 만들어줘.


그리고 실행 파일 및 저장 경로 설정에는 애초부터 내 기존 경로가 박혀있는데 이건 좀 부담스러우니 아예 빈칸으로 GUI에 띄우고 진짜 빈칸이면 그 때 내 경로를 넣어.
