video_downloader_gui.py 파일은 GUI까지 기능 구현이 완료되었으니
이제 본격적인 다용도 툴이 될 수 있도록 여러가지 기능을 추가할거야.
지금까지 따로 따로 사용하고 있던 다른 툴에 대해 설명해줄게. 이걸 방금 언급한 파일에 병합시키는 것이 목표야.
하나의 통합 프로그램을 만들고 각 탭을 클릭해서 원하는 기능을 사용할 수 있도록 하는 거지

1. yt_clip_manager
동영상/음원 파일을 원하는 시간대에 맞게 n개로 커팅하고, 병합하는 기능.
내 기억상으로 파일이 깨지지 않도록 커팅하게 만들었던 것 같은데 관련 기술은 잘 몰라서 너가 코드 뜯어서 확인해줘.
최종적인 목표는 드래그&드롭이나 찾아보기 버튼을 이용해서 편집할 영상을 찾는 기능을 추가하고,
"-1313, 2320-2330, 13130-" 같이 시간 정보를 타이핑해서 커팅하던 기존 방식에서 GUI 상에서 영상이 미리 보이고, 바 두 개를 움직여서(혹은 타이핑 가능) 커팅 구간을 지정하는거야.
"+" 버튼을 입력하면 새로운 커팅 구간을 지정할 수 있고, merge 여부를 체크해서 각각 독립적인 영상 파일로 만들지 아니면 병합할지 선택하는거야. 어려운 기능이라면 기존 방식을 일단 유지하고 기존 기능을 gui파일에 병합부터 하자.

2. audio_convertor
이건 딱히 별건 없고, 다운받은 영상을 음원 파일로 변경하는거야. 위의 yt_clip_manager에 합쳐도 될 것 같다는 생각이 들어.
yt_clip_manager 탭에서 영상 파일을 선택한 후, 커팅구간 설정(디폴트는 전체 구간 선택)이 된 상태에서 merge 여부 선택버튼 근처의 음원 추출 여부 버튼을 통해서 음원추출을 하는거지.
이 경우에 음원파일 확장자는 무엇으로 할 것인지 선택하게 해줘.(video_downloader_gui에선 기본 설정이 추천 설정인데 얘도 동일하게 해주면 좋아)

3. 추가사항
video_downloader_gui.py에서 도구폴더 경로를 지정했었는데, 이 프로그램이 깔린 경로가 기본위치가 되도록 하는게 배포 시 편할 것 같아. 내 개인정보(경로에 hwang이 들어간다거나)도 코드 안에 들어가서 뭔가 찝찝하거든.
영상과 음원 저장 폴더도 내 경로가 아닌 download 폴더가 디폴트가되도록 변경해줘.

* 코드는 바로 생성하는 것보다 보다 완벽한 시스템을 완성하기 위해 궁금한 점이 있으면 질문을 먼저 해줘. 한번에 만들기 어려울 것 같으니 나와 협의하면서 만들어보자.

컨트롤+n을 통해서 새로운 구간 만들기, 컨트롤+w를 이용해서 선택된 구간 지우기, 컨트롤 방향키 좌우는 각각 왼쪽, 오른쪽에 있는 구간을 선택하기.
(더 추가하면 좋을 단축키가 있다면 추천해주고, 설정창을 만들어서 아예 단축키설정을 할 수 있도록 하면 좋을 것 같은데 여긴 좀 고급영역같으니 설정창은 나중에 구현해도 돼.)

질문 3. 내 경로가 노출되지 않도록 해줘. 만약 시스템 기본 폴더 추적이 가능하다면, 기본 영상 다운 위치는 다운로드, 문서, 사진 등의 기본 폴더 중에서 동영상 폴더, 음원은 음악 폴더에 저장해주면 좋겟어.
