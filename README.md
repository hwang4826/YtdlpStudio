# YtdlpStudio

# 🎬 yt-studio (yt-dlp & FFmpeg 미디어 통합 매니저)

유튜브, 치지직(Chzzk), SOOP 등 다양한 스트리밍 플랫폼의 영상을 다운로드하고, 직관적인 타임라인 UI를 통해 손쉽게 자르고 병합할 수 있는 **All-in-One 윈도우 GUI 프로그램**입니다.

복잡한 명령어 입력 없이, 전문 영상 편집기(NLE) 스타일의 단축키를 활용하여 빠르고 무손실(Lossless)로 미디어를 가공할 수 있습니다.

## ✨ 주요 기능

### ⬇️ 1. 강력한 미디어 다운로더
* **다중 병렬 다운로드**: 여러 개의 URL을 한 번에 입력하여 빠르게 동시 다운로드합니다.
* **최적 화질 자동 선택**: 플랫폼(YouTube, SOOP, 치지직 등)의 특성에 맞춰 최적의 영상 및 오디오 포맷을 자동으로 탐색하고 병합합니다.
* **음원 자동 추출**: 영상 다운로드 완료 후 mp3, m4a, opus 등 원하는 포맷으로 즉시 오디오를 추출합니다.
* **쿠키 및 Node.js 지원**: 연령 제한이나 멤버십 전용 콘텐츠 다운로드를 위한 쿠키 적용을 완벽하게 지원합니다.

### ✂️ 2. 직관적인 미디어 편집기 (커팅 & 병합)
* **드래그 앤 드롭 지원**: 파일을 프로그램 창에 끌어다 놓으면 즉시 편집을 시작할 수 있습니다.
* **프리미어 프로 스타일 UX**: `[` 와 `]` 단축키를 이용해 영상을 보면서 실시간으로 컷팅 구간을 직관적으로 지정합니다.
* **무손실 커팅 (키프레임 탐색)**: `ffprobe`를 이용해 영상의 키프레임(I-Frame)을 자동 분석하며, `Shift + 방향키`로 키프레임 간을 이동하여 화질 저하와 오차 없는 무손실 커팅을 지원합니다.
* **스마트 구간 관리**: 겹치는 구간 자동 덮어쓰기 로직이 적용되어 오류 없는 편집이 가능합니다.
* **정밀 자르기 지원**: 1밀리초 단위의 정확한 커팅이 필요한 경우, 재인코딩 모드를 활성화할 수 있습니다.
* **다중 클립 병합**: 잘라낸 여러 구간을 하나의 완성된 파일로 깔끔하게 이어붙입니다.

### ⚙️ 3. 편의성 극대화
* **원클릭 자동 환경 설정**: 복잡한 환경변수 설정 없이, 버튼 클릭 한 번으로 공식 GitHub에서 `yt-dlp`와 `FFmpeg` 최신 버전을 자동으로 내려받아 설치합니다.
* **시스템 경로 자동 연동**: 윈도우 내 PC의 `동영상(Videos)`, `음악(Music)` 폴더를 자동으로 인식하여 기본 저장 경로로 지정합니다.

## ⌨️ 단축키 안내 (미디어 편집기)

전문가 수준의 빠른 편집을 위한 단축키를 지원합니다.

| 단축키 | 기능 설명 |
| --- | --- |
| `Space` | 영상 재생 / 일시정지 |
| `[`, `]` | **구간 시작 지점 설정** / **구간 확정 및 추가** |
| `←` / `→` | 5초 뒤로 / 앞으로 이동 |
| `Shift` + `←` / `→` | **이전/다음 키프레임(I-Frame)으로 점프** (무손실 컷팅용) |
| `Ctrl` + `←` / `→` | 타임라인 상의 이전/다음 컷팅 구간으로 점프 |
| `↑` / `↓` | 1분 뒤로 / 앞으로 이동 |
| `Enter` | 수동으로 입력한 시간 구간을 리스트에 추가 |
| `Delete` | 리스트에서 선택한 구간 삭제 |
