# 🎬 yt-dlp 미디어 통합 매니저 (yt-dlp Studio)

![Version](https://img.shields.io/badge/version-v1.3.1-blue.svg)
![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)
![PyQt6](https://img.shields.io/badge/PyQt6-UI-green.svg)

**yt-dlp 미디어 통합 매니저**는 강력하지만 명령어가 복잡해 다루기 어려웠던 `yt-dlp`와 `FFmpeg`를 누구나 쉽게 클릭만으로 다룰 수 있도록 만든 **All-in-One GUI 프로그램**입니다. 

## 🤔 만든 이유 (Motivation)
유튜브 및 스트리밍 플랫폼에서 영상과 음원을 다운로드할 때 가장 우수한 툴은 단연코 CLI 기반의 `yt-dlp`입니다. 하지만 일반 사용자가 매번 긴 명령어를 치는 것은 불편합니다. 더 나아가, 다운로드한 결과물을 **내가 원하는 구간만 자르고**, **여럿으로 나누어진 파일을 하나로 합치고**, 삼성뮤직이나 스마트폰에서 예쁘게 보이도록 **음원 앨범아트 및 메타데이터를 넣으려면** 여러 개의 서드파티 프로그램을 오가며 작업해야 하는 엄청난 '노가다'가 발생합니다.

이러한 불필요한 과정과 화질/음질의 훼손(재인코딩)을 막고, **"다운로드부터 미디어 컷편집, 무손실 병합, 대량 음원 추출, 태그 삽입까지 단 하나의 프로그램에서 끝내자"**는 목표로 이 프로젝트를 개발했습니다.

## 💻 탭(Tab)별 기능 설명

### 1. ⬇️ 미디어 다운로더
복잡한 옵션 없이 URL만 넣으면 **최고 화질(AV1, VP9)과 최고 음질**을 자동으로 병렬 다운로드합니다.
* 다중 URL 입력 및 다중 스레드 병렬 다운로드 지원 (최대 5개 동시)
* 재생목록(`&list=`) 스마트 파싱 (원치 않는 목록 다운로드 방지)
* m3u8(SOOP, 치지직 등) 다이렉트 링크 완벽 지원
* 쿠키 파일 지원으로 멤버십 영상 다운로드 가능

### 2. ✂️ 미디어 편집기
무거운 영상 편집기를 켤 필요 없이, 직관적인 타임라인으로 영상을 정밀하게 자를 수 있습니다.
* `0.1초` 및 `0.001초` 단위의 초정밀 구간 자르기 지원
* 여러 구간을 잘라내어 하나의 파일로 병합 가능
* 영상에서 특정 구간만 음원으로 즉시 추출 가능

### 3. 🔗 비디오 병합기
나누어져 있는 여러 개의 영상을 마우스 드래그 앤 드롭으로 넣고 순식간에 하나로 합칩니다.
* **무손실 초고속 병합:** 해상도와 프레임이 같은 영상은 재인코딩 없이 1초 만에 병합됩니다.
* **스마트 재인코딩:** 규격이 다른 영상이 섞여 있을 경우, 사용자가 지정한 해상도/프레임에 맞춰 시각적 무손실 수준(`-crf 18`)으로 안전하게 합쳐주며, 오디오는 100% 무손실 복사(`-c:a copy`)됩니다.

### 4. 🎙️ 음원 일괄 추출기
여러 개의 비디오 파일에서 오디오만 뽑아내고 싶을 때 사용하는 대량 처리 도구입니다.
* 다수 파일 드래그 앤 드롭 및 5개 파일 동시 병렬 추출
* 확장자 **'추천'** 선택 시 원본 코덱을 자동 분석하여 재인코딩(음질 열화) 없이 100% 원본 껍데기만 무손실로 추출합니다.

### 5. 🎵 음원 태그 편집기 (메타데이터 에디터)
스마트폰(삼성뮤직, 애플뮤직 등)에서 앨범아트와 가수 이름이 제대로 뜨도록 관리합니다.
* `mutagen` 엔진 기반으로 재인코딩 없이 **0.1초 만에 텍스트 및 이미지 덮어쓰기**
* 파일명 자동 파싱: `-` 기호를 기준으로 `음악가-앨범명-곡번호-제목` 형태를 스마트하게 분석하여 빈칸을 알아서 채워줍니다.
* 여러 곡을 다중 선택하여 앨범명, 가수, 앨범아트를 한 번에 **일괄 적용**할 수 있습니다.
* 앨범아트 이미지 파일(.jpg, .png) 드래그 앤 드롭 지원

## 🛠 설치 및 실행 방법
1. 파이썬(Python 3.8 이상)을 설치합니다.
2. 필수 라이브러리를 설치합니다: `pip install PyQt6 mutagen`
3. 프로그램 내의 `[🛠 필수 도구 설치]` 버튼을 눌러 `yt-dlp`와 `FFmpeg`를 자동 다운로드하면 즉시 사용할 수 있습니다!
